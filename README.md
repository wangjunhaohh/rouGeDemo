# testRou

基于项目内多 Agent 约束生成并持续迭代的 Godot 4 俯视角 2D 肉鸽原型。

当前状态已经从 `v0.1` 闭环原型推进到 `v0.9`：

- 暗黑像素风背景与像素角色/敌人/投射物素材已接入
- 命中、受击、击杀、升级、精英与 Boss 均有反馈与音效
- 加入精英怪、Boss、Boss 二阶段技能与局外成长
- 刷怪节奏改成阶段式推进，敌人组合差异更明显
- 升级池权重与数值做了第二轮校正
- 升级项已加入联动效果，局外成长扩展为带前置条件的分支
- 战局已改成首领目标战，不再是固定 10 分钟结束
- 地图中已接入特殊技能卡事件
- 玩家主武器已补上像素武器演出与开火闪光
- HUD 与事件面板已做一轮暗黑像素主题化收口
- 开局已加入 3 条主分支选择，并影响本局升级刷新倾向
- 不同主分支现在拥有可辨识的核心机制，而不只是被动数值差异
- 肉盾流可触发近身震荡护环，并在受击时反震清压
- 异常流会周期抛出蚀火法球，落地生成减速灼地区域
- 召唤流的哨戒节点会自主射击，并周期释放压制脉冲
- 每个主分支都已接入 3 个专属升级收益，构筑节点更完整
- 升级三选一会优先支持主分支成型，并尽量保留 1 个非主分支补强位
- 升级与特殊抉择现在都会暂停全局
- 角色死亡后不再继续生成子弹、灼地与召唤链路
- 三条主分支的主武器已拆成 `近战挥砍 / 施法投掷 / 指令射击` 三种攻击范式
- 肉盾流现在使用专属刀刃帧，按 `起手 -> 挥砍命中 -> 收势` 节奏进行真实近战判定
- 异常流现在使用专属法杖帧与法球贴图，主攻击改为施法后抛出旋转火种
- 召唤流现在使用专属中继器帧与信号弹贴图，主攻击改为充能后释放指令弹
- 分支武器像素帧已由独立脚本生成，并接入运行时纹理加载链路
- 三条主分支的主攻击已接入 `art/spine/` 目录下的 Spine 导出帧清单
- 玩家主武器表现已拆成 `Weapon / WeaponTrail / WeaponImpact` 三层播放
- 分支攻击命中时机已支持按 `Spine` 清单中的 `hit_frame_progress` 对齐
- `Player` 场景已切到 `AnimatedSprite2D + Hurtbox + AttackPoint + WeaponPivot + SlashHitbox + AnimationPlayer` 标准结构
- 近战主体动画已接入 6 帧剑攻击顺序图，并按 `idle -> ready -> slash -> followthrough -> recover -> idle_end` 顺序切换

## 当前内容

- 1 个可玩角色
- 8 类常规敌人 + 精英变体 + 1 个 Boss
- 3 个开局主分支，每条分支都有独立核心机制
- 自动攻击主武器（已区分近战挥砍 / 施法投掷 / 指令射击）
- 可解锁的脉冲副武器
- 肉盾反震护环、蚀火法球和灼地区域、哨戒节点压制脉冲
- 3 次地图特殊技能卡事件
- 19 个升级项
- 8 个局外成长项
- 经验掉落与升级三选一
- 阶段推进到 Boss 降临的战局目标
- HUD、暂停、结算、局外成长购买与重开

## 操作

- `WASD` / 方向键：移动
- `Esc` / `P`：暂停
- `R`：结算后重开

## 素材说明

本项目中的暗黑像素风背景、角色贴图与音效均为本地脚本生成，不依赖外部手工导入素材。

武器特效攻击动画正式资源目录已切到 `art/spine`，当前工程通过读取 `Spine` 导出帧清单来驱动主攻击演出。

- 背景与像素贴图生成脚本：`scripts/tools/generate_pixel_assets.gd`
- 分支武器帧生成脚本：`scripts/tools/generate_branch_weapon_frames.gd`
- 音效生成脚本：`scripts/tools/generate_audio_assets.py`
- 背景资源目录：`art/backgrounds`
- 贴图资源目录：`art/sprites`
- Spine 攻击资源目录：`art/spine`
- 音效资源目录：`audio/sfx`

## 核心循环

1. 玩家进入战斗并自动攻击最近敌人
2. 击败敌人后掉落经验
3. 升级时暂停，并从优先偏向主分支、但保留补强位的 3 个成长项中选择 1 个
4. 战斗开始前先选择本局主分支，决定基础机制、成长倾向和核心武器方向
5. 战斗中会出现特殊技能卡，拾取后可获得一次高收益但可能带代价的额外选择
6. 随阶段进入不同战斗压力，面对混编敌群、精英和 Boss
7. 在首领现身后击败 Boss 即获胜，失败则进入结算
8. 结算时获得暗核碎片，可购买局外成长
