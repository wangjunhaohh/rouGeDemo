# 暗核余烬

基于项目内多 Agent 约束生成并持续迭代的 Godot 4 俯视角 2D 肉鸽原型。

当前状态已经从 `v0.1` 闭环原型推进到 `v0.14`：

- 游戏名称已确定为“暗核余烬”
- 启动后先进入首页，不再直接弹出人物选择
- 首页提供开始游戏入口和人物成长入口
- 每局结算会产出暗核碎片，碎片用于首页人物技能树成长
- 暗黑像素风背景与像素角色/敌人/投射物素材已接入
- 命中、受击、击杀、升级、精英与 Boss 均有反馈与音效
- 加入精英怪、Boss、Boss 二阶段技能与局外成长
- 刷怪节奏改成阶段式推进，敌人组合差异更明显
- 升级池已收敛为通用成长 + 流派专属，避免无关卡干扰主分支成型
- 升级项已加入联动效果，局外成长扩展为带前置条件的分支
- 战局已改成首领目标战，不再是固定 10 分钟结束

- HUD 与事件面板已做一轮暗黑像素主题化收口

- 经验掉落与升级三选一
- 开局人物选择与人物专属技能

- 结算暗核碎片收益

## 操作

- `WASD` / 方向键：移动
- `Esc` / `P`：暂停
- `Space`：释放人物专属技能
- `R`：结算后重开

## 素材说明

本项目中的暗黑像素风背景、角色贴图与音效均为本地脚本生成，不依赖外部手工导入素材。

武器特效攻击动画正式资源目录已切到 `art/spine`，当前工程通过读取 `Spine` 导出帧清单来驱动主攻击演出。

- 背景与像素贴图生成脚本：`scripts/tools/generate_pixel_assets.gd`
- 分支武器帧生成脚本：`scripts/tools/generate_branch_weapon_frames.gd`
- 音效生成脚本：`scripts/tools/generate_audio_assets.py`
- 背景资源目录：`art/backgrounds`
- 贴图资源目录：`art/sprites`
- Spine 攻击资源目录：`art/spine`
- 音效资源目录：`audio/sfx`

## 核心循环

1. 玩家进入首页，可查看碎片余额和人物技能树
2. 在首页消耗暗核碎片升级人物基础属性或专属技能强化
3. 点击开始游戏后选择出战人物，获得对应基础属性、专属技能和已解锁的人物成长
4. 再选择本局主分支，决定基础机制、成长倾向和核心武器方向
5. 进入战斗并自动攻击最近敌人，必要时按 Space 释放专属技能
6. 击败敌人后掉落经验
7. 升级时暂停，并从前两张偏主分支、第三张偏通用成长的 3 个成长项中选择 1 个
8. 战斗中会出现特殊技能卡，拾取后可获得一次高收益但可能带代价的额外选择
9. 随阶段进入不同战斗压力，面对混编敌群、精英和 Boss
10. 在首领现身后击败 Boss 即获胜，失败则进入结算
11. 结算时获得暗核碎片，返回首页后继续投入人物成长

## 当前仍需继续优化

- 异常流已有 6 类基础异常和头顶短标，但 DOT、传播、崩解仍复用基础色条与 GuardBurst 表现，后续需要替换成独立状态图标和专属 Spine 特效
- 肉盾流已有大剑、震地重击、格挡、护盾破裂反击和霸体窗口，但盾击、突进等武器分支还需要独立动画资源和专属攻击判定
- 主分支系统已经进入差异化版本，但仍可继续补更多专属技能方向和更强的中后期成型节点
- 特殊技能卡已经扩到 8 个配置项，但仍使用通用图标，后续需要补分支专属图标和更极端的风险收益组合
- 局外成长已经扩到 10 个节点，但资源回路仍以暗核碎片为主，后续可继续增加更多路线和资源用途
- Boss 已有分支针对性开场压力波，但场景变化、胜利结算演出和多阶段针对机制仍需要继续强化
- 近战挥砍、法球抛射和指令弹发射已经切到 Spine 导出帧链路，但真实美术资源替换后仍需继续细调命中前摇、判定宽度、残影幅度和角色动作节奏
- 升级卡片 UI 已补充类型标识和更稳定的排版，后续仍需要独立图标、关键词高亮和 hover/选中态统一样式
