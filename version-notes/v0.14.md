# v0.14

## 版本目标

本版本补上正式首页，把游戏名称定为“暗核余烬”，并把每局收益接入可扩展的角色成长系统。玩家启动后先进入首页，可消耗暗核碎片升级剑客 / 法师各自独有的人物技能树，再开始新一局。

## 本次新增内容

- 游戏名称更新为“暗核余烬”
- 新增首页 UI，不再一进场就直接选择人物
- 首页提供两个核心入口：开始游戏、人物成长
- 新增人物技能树绘制，支持节点连线、前置依赖、等级、花费和锁定状态
- 暗核碎片继续作为结算收益，并作为人物技能树消耗货币
- 剑客新增独立成长树：普攻伤害、生存护甲、技能伤害、移速暴击、技能冷却 / 范围
- 法师新增独立成长树：法术强度、生存护甲、技能伤害、技能范围、技能冷却 / 法强
- 结算面板改为展示本局碎片收益，返回首页后再进行人物成长投入

## 验收对照

### Design Agent

- 首页不是营销页，而是可直接进入游戏和人物成长的操作界面
- “暗核余烬”与现有暗街、余烬、暗核碎片、美术氛围保持一致
- 人物成长没有做成通用模板：剑客偏近战爆发和切入，法师偏法术范围和轰炸
- 技能强化节点放在后置路径，避免第一局后直接压过局内构筑

### Code Agent

- 碎片仍复用 `MetaProgression` 存档链路
- 角色成长以 `character_id -> upgrade_id -> level` 存储，后续新增角色可继续扩展
- 成长节点定义包含坐标、前置、花费、等级和效果字段，UI 不硬编码节点内容
- `GameManager` 只负责首页流程和购买转发，具体数据仍在 `MetaProgression`
- 玩家战斗属性通过现有 `apply_meta_bonus()` 入口扩展，未新增独立属性应用分支

### Playtest Agent

- 需要验证启动后首页是否稳定出现
- 需要验证开始游戏入口是否进入人物选择，再进入主分支选择
- 需要验证人物技能树节点可读性、连线关系和锁定状态
- 需要验证碎片购买、保存、重启后保留
- 需要验证角色成长对下一局是否生效，并观察强度是否合理

## 已知问题

- 首页人物树目前使用文本节点和连线，后续可替换为角色立绘、图标和更明确的节点状态样式
- 角色树第一版每人 5 个节点，已覆盖基础属性和技能强化，但还没有多分支专精路线
- 结算后的碎片消费入口已迁到首页，旧全局成长仍保留在存档系统中但本轮不再作为主要 UI 展示
- 本轮自动验证已覆盖编辑器解析、运行时启动、导出和导出版启动，仍需要人工试玩验证按钮点击、购买保存和数值体感
