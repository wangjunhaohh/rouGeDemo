# v0.8

## 版本目标

承接 [v0.7.md](D:\javaweb\godot\rouGeDemo\test-rou\version-notes\v0.7.md) 已完成的分支武器动作差异化，这一版把正式战斗表现落实到代码：主攻击动画链路改为读取 `art/spine` 下的 Spine 导出帧清单，角色主武器表现拆成 `武器本体 / 轨迹特效 / 命中特效` 三层，并按资源清单中的命中时机驱动攻击判定。

## 本次新增内容

- 新增 `art/spine/branch_attacks/` 资源目录，并为 `tank / debuff / building` 三条分支补上 Spine 导出帧清单
- `BranchCatalog` 现在会读取 `manifest.json`，把 `animation_source / spine_asset_key / spine_animation / spine_event_track / vfx_spine_key / hit_frame_progress` 注入分支定义
- `Player` 主武器表现改为消费 `weapon_sequences / trail_sequences / impact_sequences`
- 玩家节点结构从原先的 `Weapon + WeaponFlash` 改为 `Weapon + WeaponTrail + WeaponImpact`
- 主攻击命中时机改为按分支配置的 `hit_frame_progress` 提前结算，不再固定卡到前摇结束的最后一帧

## 具体调整

- 新增 `art/spine/README.md`，约定 Spine 资源目录结构和后续替换方式
- 新增三份分支清单：
  - `art/spine/branch_attacks/tank/manifest.json`
  - `art/spine/branch_attacks/debuff/manifest.json`
  - `art/spine/branch_attacks/building/manifest.json`
- `scripts/data/branch_catalog.gd` 新增：
  - Spine 清单读取
  - 纹理缓存
  - 序列帧字典装配
- `scripts/actors/player.gd` 新增：
  - 分支级 `Spine` 元数据字段
  - 序列帧标准化与取帧逻辑
  - `WeaponTrail / WeaponImpact` 分层播放
  - `hit_frame_progress` 驱动的攻击命中同步
- `scenes/player/player.tscn` 新增 `WeaponImpact` 节点，并将原先单层闪光拆分为轨迹层和命中特效层

## 当前状态

- 三条主分支已经从单张武器帧切换为按阶段读取的 Spine 导出帧序列
- 玩家攻击演出已经具备 `武器本体 / 轨迹特效 / 命中特效` 分层
- 分支逻辑层仍沿用 `v0.7` 的近战挥砍、施法投掷、指令射击三种攻击范式，但表现层已切到 `art/spine`
