# v0.13

## 版本目标

本版本根据 `role-md` 新增的多人物系统规范，落地第一阶段最小可玩版本：开局人物选择、剑客 / 法师基础属性、两个人物专属技能，以及对应的导出链路验证。

## 本次新增内容

- 新增开局人物选择流程，先选人物，再选本局主分支
- 新增 `CharacterCatalog`，用数据表维护人物基础属性和专属技能参数
- 新增剑客人物：高攻击近战爆发，基础暴击 8%，护甲 2
- 新增法师人物：范围法术压制，较低生命，技能范围修正 10%
- 新增剑客专属技能“瞬影剑阵”：5 段残影斩击，同一目标最多命中 4 次，释放期间 50% 承伤
- 新增法师专属技能“环域轰炸”：跟随角色的轰炸法阵，周期生成预警点并爆炸
- 新增 `Space` 专属技能输入
- HUD 新增专属技能状态行，技能释放后按整秒显示剩余冷却，就绪时提示 `Space`
- 新增人物选择 UI，并保持与现有分支选择 / 升级选择面板一致的弹窗结构

## 验收对照

### Design Agent

- 剑客不只是换皮：基础属性偏攻击和暴击，专属技能为多段近战斩击
- 法师不只是换皮：基础属性偏法术强度和范围，专属技能为跟随轰炸法阵
- 人物与流派拆开：人物先确定起始战斗风格，主分支仍作为局内成长方向
- 两个人物都有明确弱点：剑客切入风险更高，法师生命更低且怕贴脸

### Code Agent

- 人物和技能数据集中在 `CharacterCatalog`，没有把人物配置硬编码进主流程
- `GameManager` 只负责流程状态和输入转发
- 专属技能通过统一 `try_use_exclusive_skill()` 入口调用
- 技能表现拆到独立效果脚本，避免继续扩大 `GameManager`
- 本轮涉及主场景、UI、主流程、玩家和新增脚本，已执行导出一致性验证

### Playtest Agent

- 本轮自动验证覆盖：项目解析、导出包生成、导出版启动、人物选择面板资源加载
- 仍需人工复测：
  - 开局选择剑客 / 法师后是否能明显感受到玩法差异
  - 剑客 5 段斩击是否过强或过弱
  - 法师轰炸预警是否足够清晰
  - `Space` 技能冷却秒数的位置、字号和可读性是否足够
