# v0.12

## 版本目标

本版本聚焦升级卡选择体验和战斗命中反馈：收敛普通升级池，强化主分支成型引导，避免肉盾流继续刷出攻速、射程、穿透、散射这类不贴合的成长项，并让伤害数字直接显示在怪物头顶。

## 本次新增内容

- 普通升级池收敛为 4 类通用成长：普攻伤害、最大生命、移动速度、暴击
- 新增通用暴击升级 `critical_focus`
- 当前生效升级池从 34 个收敛为 28 个，历史资源保留但不再进入本轮普通升级抽取
- 升级三选一改为前两张优先当前流派专属，第三张优先通用成长
- 肉盾流不再混入攻速、射程、穿透、散射、脉冲类普通成长
- 升级卡 UI 增加“流派专属 / 通用成长”类型标识，并放大卡片尺寸、字号和间距
- 怪物受伤后在头顶显示伤害数字，直接伤害、异常伤害和击杀伤害使用不同颜色

## 验收对照

### Design Agent

- 升级卡需要短时间内可读：已加入类型标签，卡片更大，描述分层更清楚
- 不同分支需要有稳定成长路径：前两张升级优先主分支专属，第三张提供通用成长
- 不同分支不能只靠数值伪差异：本轮未新增分支机制，但去除了跨分支无效卡对构筑方向的干扰

### Code Agent

- 新增 `UpgradeData` 资源后已同步 `ContentCatalog.UPGRADE_DEFINITIONS`
- 改动涉及资源加载、升级定义、主流程脚本和 UI 场景，已执行导出一致性验证
- 未新增框架或大重构，继续复用现有 `UpgradeData`、`BranchCatalog`、`GameManager` 和 `Effects` 层

### Playtest Agent

- 核心专项：升级选择是否有意义、UI 信息是否清晰、攻击反馈是否明确
- 本轮可自动验证导出包启动、资源加载和脚本解析
- 升级分布、卡片主观可读性、15 到 30 分钟实机体验仍需人工试玩复测
