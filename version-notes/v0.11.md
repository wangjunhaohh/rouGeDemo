# v0.11

## 版本目标

本版本补齐 v0.10 后续未落到位的异常流、肉盾流、特殊卡、局外成长和 Boss 分支压力内容，并继续遵守 `role-md/code-agent.md` 中的导出一致性要求。

## 开发项

- 异常流新增 `诅咒 / 腐蚀 / 控制` 三类状态，接入现有统一状态容器
- 敌人新增头顶状态短标和状态色条，覆盖燃烧、中毒、迟缓、易伤、诅咒、腐蚀和控制
- 诅咒支持 DOT 与直接命中兑现，腐蚀支持按层数放大后续伤害，控制支持短时间停止移动与接触伤害
- 异常死亡传播不再只传播中毒，会根据死亡目标实际携带状态传播燃烧、中毒、诅咒、腐蚀和短控
- 肉盾流新增格挡、临时护盾、护盾破裂反击、霸体窗口和震地重击
- 肉盾近战命中保留真实近战判定，重击只强化现有近战命中帧，不退回隐藏子弹模拟
- Boss 开场新增按主分支生成的针对性压力波
- 特殊技能卡新增异常风险卡 `灾厄标本` 与肉盾风险卡 `壁垒试验`
- 局外成长新增 `战地注剂` 与 `军械暗仓`
- 新增 8 个分支升级项，升级总量从 26 扩展到 34

## 新增升级项

- `shadow_brand`：诅咒伤害与持续时间
- `acid_etching`：腐蚀削防与持续时间
- `binding_hex`：短控概率与持续时间
- `calamity_vector`：异常传播范围与崩解伤害
- `tower_guard`：护盾上限与格挡概率
- `shield_breaker`：护盾破裂反击伤害与范围
- `hammer_slam`：震地重击触发间隔与伤害
- `unyielding_core`：格挡承伤倍率与霸体时间

## 关键逻辑

- 敌人状态继续走统一 `_statuses` 容器，新增状态只扩展 `STATUS_CONFIGS`，避免回到零散字段
- 玩家分支参数继续由 `BranchCatalog` 和 `UpgradeData` 驱动，新增升级项必须进入 `ContentCatalog.UPGRADE_DEFINITIONS`
- 近战重击、护盾破裂和格挡反击复用 `GuardBurst` 导出安全场景，避免新增未验证资源链路
- 主分支武器动画继续从 `art/spine/branch_attacks/*/manifest.json` 读取，未直接接入 Spine runtime 时仍使用 Spine 导出帧
