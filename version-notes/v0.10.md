# v0.10

## 版本目标

承接 [v0.9.md](D:\javaweb\godot\rouGeDemo\test-rou\version-notes\v0.9.md) 已完成的角色结构和主武器动画链路，这一版把 `role-md/Genre-Gameplay/abnormal_branch_design.md` 与 `role-md/Genre-Gameplay/tank_branch_design.md` 的第一轮核心玩法落到代码。重点不是继续堆分支描述，而是把异常流和肉盾流真正做成能在战斗中成立的系统链路。

## 本次新增内容

- 敌人状态承载从零散的 `burn / slow` 字段收口成统一状态容器
- 异常流正式接入 `燃烧 / 中毒 / 易伤` 三状态，以及 `叠层 / 异常增伤 / 死亡传播 / 异常崩解`
- 肉盾流正式接入 `护甲 / 贴脸增伤 / 受击反伤 / 击杀回血 / 低血减伤`
- 主武器投射物和脉冲波现在都支持多状态挂载与“对异常目标增伤”结算
- 新增 7 个异常流与肉盾流专属升级，并同步注册到 `ContentCatalog`

## 具体调整

- `scripts/actors/enemy.gd`
  - 新增统一状态容器和状态快照输出

  - `poison` 现在支持叠层与阈值崩解
  - 死亡信号新增状态快照参数，供分支逻辑做传播与击杀收益
- `scripts/actors/player.gd`
  - 新增异常流分支字段：中毒、易伤、状态附加概率、传播、崩解、异常增伤
  - 新增肉盾流分支字段：护甲、贴脸增伤、反伤、击杀回血、低血减伤
  - 近战命中、投射物、脉冲波统一改为走分支状态挂载
  - 新增击杀后的异常传播与异常崩解处理
- `scripts/weapons/player_projectile.gd`
  - 从单状态挂载改为多状态挂载
  - 新增对异常目标增伤结算
- `scripts/weapons/pulse_wave.gd`
  - 从单状态挂载改为多状态挂载

- `scripts/core/game_manager.gd`

- `scripts/data/branch_catalog.gd`

## 当前状态

- 异常流已经不再只是“燃烧法球 + 灼地”，而是具备基础状态闭环
- 肉盾流已经不再只是“高血 + 护环”，而是具备真实近战站场收益
- 升级池总量扩展到 26 个，其中异常流和肉盾流都补上了一轮专属成型节点
- 现有实现继续复用当前主武器链路、升级刷新链路和敌人脚本，没有为了这轮需求重起一套战斗框架

## 后续仍可继续优化

- 补更多异常类型与更强的跨状态联动，而不只停在 `燃烧 / 中毒 / 易伤`
- 给状态系统补可视化 UI 和更清晰的战斗反馈，避免现在只能靠颜色和数值体感判断
- 继续扩肉盾流的武器形态、格挡机制和更明确的霸体表现
- 等正式 Spine 美术到位后，再统一细调不同分支的动作节奏和命中前摇
