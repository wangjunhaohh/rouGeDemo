# 多人物角色设计文档：剑客与法师

> 用途：可直接放入 `design-agent.md`，或作为 `characters_branch_design.md` 单独维护。  
> 目标：在现有肉鸽框架中加入多个可选人物，每个人物拥有独立定位、基础属性倾向、专属技能和专属升级方向。

---

## 1. 多人物系统总规则

### 1.1 设计目标
- 让玩家在开局前可以选择不同人物。
- 每个人物不只是换皮，而是拥有明显不同的战斗节奏、技能机制和成长方向。
- 人物差异应与流派系统互相配合，但不能完全等同于流派。
- 同一个人物可以适配多个流派，但应有自己最擅长的成长方向。
- 人物专属技能需要成为该人物的核心记忆点。

### 1.2 人物与流派的关系
人物不是流派本身，而是“起始战斗风格”。

例如：
- 剑客：偏攻击、爆发、近战、残影、多段斩击。
- 法师：偏法术、区域轰炸、范围压制、技能循环。
- 肉盾流、异常流、建筑流等仍然是局内成长方向。

一个人物可以选择不同流派：
- 剑客 + 肉盾流：近战重甲剑士。
- 剑客 + 异常流：流血、灼烧、易伤斩击。
- 法师 + 异常流：元素轰炸、持续异常扩散。
- 法师 + 建筑流：法阵炮台、召唤轰炸阵地。

### 1.3 人物最低配置
每个人物至少需要定义：
- 人物定位
- 基础属性倾向
- 专属技能
- 专属技能升级方向
- 推荐武器类型
- 推荐流派适配
- 明显弱点
- 视觉表现关键词
- Playtest 验证重点

### 1.4 专属技能规则
每个人物拥有一个专属技能，作为该角色的核心差异点。

专属技能应满足：
- 与人物主题强绑定。
- 不应只是普通攻击的强化版。
- 需要有独立动画或明显特效。
- 可以通过局内升级获得变体。
- 可以与不同流派产生不同联动。
- 不应强到完全压过武器和升级构筑。

# 2. 人物一：剑客

## 2.1 人物名称
**暂定名：剑客**

后续可替换为更有风格的名字，例如：
- 影刃
- 白刃行者
- 流光剑士
- 瞬影客
- 月痕剑客

## 2.2 人物定位

### 核心定位
- 高攻击
- 高爆发
- 近战输出
- 多段斩击
- 短时间突进爆发
- 依赖攻击节奏和站位

### 战斗风格
剑客是一个偏进攻型人物，适合主动切入敌群，用高速剑技清理目标。

他的核心体验不是站着硬扛，而是：
- 快速接近
- 瞬间爆发
- 多段斩击
- 击杀后继续推进
- 在危险中寻找输出窗口

### 属性倾向
剑客的基础属性应偏攻击，而不是防御。

推荐基础倾向：
- 攻击力：高
- 攻击速度：中高
- 暴击率：中高
- 移动速度：中高
- 最大生命：中低
- 护甲：低
- 回复能力：低
- 技能冷却：中

### 角色弱点
- 身板较脆。
- 被围住时风险较高。
- 过度依赖切入时机。
- 面对高击退、高控制、高远程压力敌人时容易吃亏。
- 如果没有拿到生存或位移相关升级，后期容错较低。

## 2.3 剑客专属技能：瞬影剑阵

> 设计参考方向：高速残影、多段斩击、短暂无敌感、范围内连续斩杀。需要做成原创表现，不直接照搬任何现成角色技能。

### 技能名称
**瞬影剑阵**

备选名：
- 影刃乱舞
- 月影连斩
- 流光剑阵
- 无痕剑舞
- 瞬杀阵

### 技能定位
- 爆发输出技能
- 多段范围斩击
- 短时间强化剑客的清场能力
- 用于处理精英、小 Boss、密集敌群

### 核心效果
剑客进入短暂的高速剑舞状态，在目标区域或自身周围释放多段残影斩击，对范围内敌人造成连续伤害。

### 基础规则
- 释放技能后，剑客短时间进入剑阵状态。
- 技能期间生成多个残影斩击轨迹。
- 每段斩击对范围内敌人造成伤害。
- 对同一敌人可多次命中，但需要有单体命中上限，避免 Boss 秒杀失控。
- 技能期间可提供短暂无敌、减伤或不可被选中效果，但持续时间必须很短。
- 技能结束后进入短暂收招时间。

### 推荐技能参数
第一版可以先用以下参数：
- 技能冷却：18 秒
- 持续时间：1.2 秒
- 斩击次数：5 次
- 单段伤害：攻击力的 70%
- 总伤害上限：对同一目标最多命中 4 次
- 范围半径：160
- 释放期间减伤：50%
- 释放期间移动：可锁定当前位置，也可允许缓慢移动
- 收招时间：0.25 秒

### 技能表现
- 剑客瞬间进入高速状态。
- 身边出现多个残影。
- 敌人周围出现斩击线。
- 每次斩击有清晰刀光。
- 最后一击可以有更大的十字斩或圆形斩击。
- 技能结束后残影消散。

### 技能动画需求
- 起手：收剑 / 蓄势 / 身体压低
- 释放：高速残影、多段刀光
- 终结：大范围斩击或回到原位
- 收招：短暂硬直

### 命中反馈
- 每段斩击需要有轻微停顿感或闪光。
- 命中敌人时触发刀痕、火花或冲击。
- Boss 被多段命中时不能过度遮挡画面。
- 普通敌人可被轻微击退。

## 2.4 剑客专属技能升级方向

### 方向 A：多段斩击强化
强化斩击数量和伤害频率。

升级示例：
- 斩击次数 +1
- 技能持续时间 +0.2 秒
- 每次斩击伤害提高
- 最后一击伤害提高
- 对生命低于一定比例的敌人造成额外伤害

适合流派：
- 攻击流
- 暴击流
- 近战流

### 方向 B：残影分身强化
让技能产生残影或额外攻击源。

升级示例：
- 释放技能时生成 1 个残影协同斩击
- 残影继承部分攻击力
- 残影优先攻击最近敌人
- 技能结束后残影保留短暂时间
- 残影攻击可触发部分近战效果

适合流派：
- 召唤流
- 攻击流
- 异常流

### 方向 C：生存闪避强化
提升剑客释放技能时的安全性。

升级示例：
- 释放期间短暂无敌
- 释放期间减伤提高
- 技能结束后获得护盾
- 技能命中敌人时回复少量生命
- 技能击杀敌人后减少冷却

适合流派：
- 肉盾流
- 近战流
- 高风险爆发流

### 方向 D：异常斩击强化
让剑阵附带异常状态。

升级示例：
- 斩击附加流血
- 斩击附加灼烧
- 斩击使敌人易伤
- 对异常状态敌人造成额外伤害
- 技能最后一击扩散目标身上的异常状态

适合流派：
- 异常流
- 负面状态流
- 火焰 / 毒 / 诅咒构筑

## 2.5 剑客推荐武器

### 1. 长剑
- 类型：近战挥砍
- 攻击方式：中距离弧形斩击
- 定位：标准武器
- 特点：攻速和范围均衡
- 适合：新手、主线构筑

### 2. 双刀
- 类型：近战高速连击
- 攻击方式：短距离快速多段
- 定位：高频输出
- 特点：触发频率高，单次伤害低
- 适合：暴击、异常、吸血

### 3. 大太刀
- 类型：近战重斩
- 攻击方式：慢速大范围斩击
- 定位：爆发清场
- 特点：高伤害、高前摇
- 适合：重击、范围、蓄力

### 4. 飞剑
- 类型：近战 / 远程混合
- 攻击方式：剑气或短距离飞剑
- 定位：安全输出
- 特点：牺牲一部分近战爆发，换取稳定输出
- 适合：法术剑客、异常剑客

## 2.6 剑客专属升级卡

### 普通级
- **锋刃训练**：攻击力提高。
- **快剑**：攻击速度提高。
- **剑距掌控**：近战攻击范围提高。
- **轻步**：移动速度提高。
- **破绽打击**：对近距离敌人造成额外伤害。

### 稀有级
- **残影一闪**：攻击时有概率追加一次低伤害残影斩击。
- **剑势积累**：连续攻击同一目标时伤害逐渐提高。
- **锋刃回流**：近战命中时小幅减少专属技能冷却。
- **切入姿态**：进入敌群时短暂提高暴击率。
- **剑气外放**：近战攻击额外释放短距离剑气。

### 史诗级
- **无痕连斩**：专属技能斩击次数增加。
- **终式强化**：专属技能最后一击造成更高范围伤害。
- **破阵剑意**：专属技能命中精英和 Boss 时额外造成伤害。
- **以攻为守**：短时间内连续命中敌人后获得护盾。
- **残月追击**：击杀敌人后下一次攻击变为强化斩击。

### 传奇级
- **万刃归一**：专属技能每命中一个敌人，最后一击伤害提高。
- **剑影无双**：释放专属技能时生成多个残影同步攻击。
- **瞬杀领域**：专属技能范围内低生命敌人受到斩杀伤害。
- **不灭剑心**：濒死时自动释放一次弱化版瞬影剑阵，每局有触发次数限制。
- **剑意沸腾**：每次释放专属技能后，短时间内所有近战攻击变为强化攻击。

# 3. 人物二：法师

## 3.1 人物名称
**暂定名：法师**

后续可替换为更有风格的名字，例如：
- 星术师
- 奥术使
- 轰鸣法师
- 灾厄术士
- 环爆巫师

## 3.2 人物定位

### 核心定位
- 法术输出
- 范围轰炸
- 区域压制
- 中远距离作战
- 技能循环
- 通过法术区域控制战场

### 战斗风格
法师不靠近身攻击，而是通过法术轰炸和范围控制消灭敌人。

核心体验：
- 站位拉扯
- 法术轰炸
- 控制敌人进入危险区域
- 用技能制造安全空间
- 在敌群中形成持续伤害区域

### 属性倾向
法师的基础属性应偏技能和范围输出。

推荐基础倾向：
- 法术伤害：高
- 技能范围：高
- 技能冷却：中
- 普通攻击：低
- 移动速度：中
- 最大生命：低
- 护甲：低
- 能量恢复：中高

### 角色弱点
- 身板脆。
- 被敌人贴脸后危险。
- 前期技能冷却较长时容易空窗。
- 需要依赖范围和位置控制。
- 如果地图过窄或敌人冲刺过强，会明显提高压力。

## 3.3 法师专属技能：环域轰炸

### 技能名称
**环域轰炸**

备选名：
- 奥术轰炸圈
- 星陨环域
- 魔能坠落
- 灾星法阵
- 环爆术式

### 技能定位
- 范围持续输出技能
- 自身周围生成轰炸圈
- 用于清理围攻敌人和压制战场
- 适合法术流、异常流、区域流

### 核心效果
法师在自身周围生成一个持续存在的轰炸圈，轰炸圈范围内随机落下多次法术轰炸，对敌人造成范围伤害。

### 基础规则
- 释放技能后，以法师自身为中心生成一个圆形轰炸区域。
- 轰炸区域持续数秒。
- 区域内随机位置周期性落下魔法爆炸。
- 每次爆炸对小范围敌人造成伤害。
- 爆炸可附带元素效果，例如灼烧、减速、易伤。
- 轰炸圈可以跟随法师移动，也可以固定在释放位置，需要根据手感决定。

### 推荐第一版方案
第一版建议使用“跟随法师移动”的轰炸圈。

原因：
- 更符合人物专属技能。
- 玩家能主动带着轰炸圈走位。
- 被围攻时更容易救场。
- 操作感比固定区域更强。

### 推荐技能参数
第一版可以先用以下参数：
- 技能冷却：16 秒
- 持续时间：4 秒
- 轰炸圈半径：180
- 轰炸间隔：0.35 秒
- 每次轰炸数量：1
- 单次轰炸半径：45
- 单次伤害：法术强度的 90%
- 释放时是否击退近身敌人：可以有轻微击退
- 是否跟随角色：第一版建议是

### 技能表现
- 法师脚下展开圆形法阵。
- 法阵边缘持续发光。
- 区域内随机出现落点预警。
- 短暂延迟后落下魔法爆炸。
- 爆炸可以是奥术、火焰、雷电或星光表现。
- 技能结束时法阵碎裂消散。

### 技能动画需求
- 起手：举杖 / 抬手 / 法阵展开
- 持续：法阵跟随角色，周期性轰炸
- 结束：法阵熄灭，残光消散

### 命中反馈
- 轰炸落点要有短暂提示，避免玩家看不懂。
- 爆炸要有明显范围边界。
- 多次轰炸不能造成画面过度混乱。
- 敌人受击时需要有法术冲击反馈。

## 3.4 法师专属技能升级方向

### 方向 A：轰炸频率强化
提升技能总输出。

升级示例：
- 轰炸间隔缩短。
- 每次轰炸数量增加。
- 持续时间增加。
- 轰炸命中敌人后追加小爆炸。
- 对同一目标连续命中时伤害提高。

适合流派：
- 法术输出流
- 范围轰炸流
- 暴击法术流

### 方向 B：区域范围强化
提升控制和覆盖能力。

升级示例：
- 轰炸圈半径增加。
- 单次爆炸半径增加。
- 法阵持续时间增加。
- 轰炸圈边缘对敌人造成减速。
- 法阵内敌人受到更多伤害。

适合流派：
- 控场流
- 地图压制流
- 异常流

### 方向 C：元素异常强化
让轰炸附带异常状态。

升级示例：
- 爆炸附加灼烧。
- 爆炸附加减速。
- 爆炸附加易伤。
- 爆炸有概率附加诅咒。
- 轰炸命中异常敌人时扩散异常。

适合流派：
- 异常流
- 灼烧流
- 诅咒流

### 方向 D：防御自保强化
让法师用技能保护自己。

升级示例：
- 释放技能时击退周围敌人。
- 技能持续期间获得护盾。
- 轰炸圈内敌人移速降低。
- 法阵中心区域为法师提供减伤。
- 每次轰炸命中敌人时回复少量护盾。

适合流派：
- 法师生存流
- 肉盾混搭
- 控场流

## 3.5 法师推荐武器

### 1. 奥术法球
- 类型：法术弹体
- 攻击方式：自动发射法球
- 定位：标准法师武器
- 特点：弹道稳定，可联动范围和元素

### 2. 火焰法球
- 类型：投掷 / 区域法术
- 攻击方式：投到地面后生成燃烧区域
- 定位：灼烧与区域压制
- 特点：适合异常流和持续伤害流

### 3. 雷电链
- 类型：连锁法术
- 攻击方式：命中后在敌人之间跳跃
- 定位：清杂
- 特点：适合高密度敌群

### 4. 星陨术
- 类型：延迟轰炸
- 攻击方式：目标区域短暂预警后落下陨石
- 定位：高伤害范围打击
- 特点：爆发强，但需要敌人停留在范围内

## 3.6 法师专属升级卡

### 普通级
- **法术增幅**：法术伤害提高。
- **扩散术式**：法术范围提高。
- **冷却修正**：技能冷却降低。
- **奥术专注**：站立短时间后法术伤害提高。
- **魔力回流**：击杀敌人后恢复少量能量或减少技能冷却。

### 稀有级
- **双重落点**：环域轰炸每轮有概率生成额外轰炸。
- **法阵扩张**：专属技能半径提高。
- **余波爆裂**：轰炸命中后产生小范围余波。
- **元素注入**：轰炸随机附加一种元素异常。
- **防护术式**：释放专属技能时获得护盾。

### 史诗级
- **星陨连锁**：轰炸击杀敌人后额外触发一次小轰炸。
- **奥术领域**：轰炸圈内敌人受到的法术伤害提高。
- **灾变回响**：每第 5 次轰炸变为大型爆炸。
- **重叠术式**：法阵持续期间再次释放部分法术会在圈内复制一次弱化效果。
- **元素扩散**：被轰炸命中的异常敌人会将异常状态扩散给附近敌人。

### 传奇级
- **天穹坠落**：环域轰炸结束时落下一次巨型终结轰炸。
- **永续法阵**：轰炸命中敌人可略微延长法阵持续时间，有上限。
- **灾星领域**：轰炸圈内持续降低敌人移速与抗性。
- **双环术式**：生成内外两层轰炸圈，内圈高伤，外圈控制。
- **奥术风暴**：技能持续期间轰炸频率随时间逐渐提高。

# 4. 剑客与法师的差异化要求

## 4.1 操作差异
### 剑客
- 主动贴近敌人。
- 靠斩击爆发和机动性输出。
- 需要处理切入风险。
- 更依赖近战攻击节奏。

### 法师
- 保持距离和区域控制。
- 靠技能范围和轰炸输出。
- 需要处理技能空窗和站位。
- 更依赖法术循环和地图控制。

## 4.2 视觉差异
### 剑客
关键词：
- 刀光
- 残影
- 剑痕
- 白光
- 高速移动
- 斩击线
- 近战冲击

### 法师
关键词：
- 法阵
- 奥术圆环
- 落点预警
- 爆炸
- 星光
- 元素粒子
- 区域光圈

## 4.3 数值差异
### 剑客
- 更高普攻伤害。
- 更高近战收益。
- 更依赖暴击和攻速。
- 生存中低。

### 法师
- 更高技能伤害。
- 更大范围。
- 更强异常和控制联动。
- 普攻偏弱，身板较脆。

- 爆炸使用 Area2D 范围检测敌人。
- 支持异常附加和元素扩展。
- 支持轰炸圈固定或跟随两种模式，第一版推荐跟随。

# 7. 对 playtest-agent 的测试要求

## 7.1 剑客测试重点
- 专属技能是否有明显爆发感。
- 技能释放是否容易理解。
- 多段斩击是否过强或过弱。
- 释放期间的无敌或减伤是否造成失衡。
- 剑客是否明显区别于远程枪械角色。
- 近战风险和输出收益是否匹配。

## 7.2 法师测试重点
- 轰炸圈是否看得清。
- 轰炸落点预警是否足够明确。
- 技能范围是否过大导致无脑清场。
- 法师被近身时是否有合理压力。
- 技能空窗期是否过长。
- 法师是否与异常流、范围流有良好联动。

## 7.3 双人物对比测试
- 玩家是否能在 1 分钟内感受到两个人物玩法差异。
- 剑客是否更像高攻击近战爆发角色。
- 法师是否更像范围法术压制角色。
- 两个人物是否都有明确弱点。
- 是否存在某个人物明显更强，导致另一个无人选择。

# 10. 设计结论

剑客和法师必须从底层体验上区分：

- 剑客是“进攻型近战爆发人物”。
- 法师是“区域型法术轰炸人物”。

剑客的爽点来自：
- 切入
- 残影
- 连斩
- 爆发
- 刀光

法师的爽点来自：
- 法阵
- 轰炸
- 范围压制
- 元素异常
- 控场

后续所有人物设计都应遵循同一原则：
**人物必须拥有独立专属技能、独立属性倾向、独立视觉语言和明确弱点。**
