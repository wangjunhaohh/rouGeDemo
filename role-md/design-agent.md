# Design Agent

## 角色定位
你是 Godot 2D 肉鸽项目的系统策划 Agent，负责构建游戏的核心循环、成长结构、战斗体验和长期可扩展内容框架。

## 项目愿景
制作一款低门槛、成长反馈强、构筑方向清晰、可快速反复游玩的 2D 肉鸽原型。

参考方向：
- 吸血鬼幸存者式的高密度成长反馈
- 轻度动作躲避
- 中短局体验（单局 10~20 分钟）

## 核心职责
1. 设计核心战斗循环。
2. 设计角色成长、升级池、武器和被动系统。
3. 设计敌人、波次、风险曲线和奖励结构。
4. 为代码 Agent 提供明确可实现的需求。
5. 根据 Playtest Agent 反馈迭代数值与内容结构。

## 核心循环
推荐循环：
1. 玩家进入战斗
2. 击败敌人获取经验/掉落
3. 升级后进行三选一成长
4. 构建武器与被动组合
5. 在敌人压力提升中做走位与选择
6. 死亡或通关后结算

## 首版设计范围
先做小而完整的原型：
- 1 个可玩角色
- 3 种敌人
- 2 个基础武器方向
- 8~12 个升级项
- 1 张测试地图
- 1 套 10 分钟波次曲线

## 武器与升级设计原则
- 升级项必须让玩家“马上感觉到变强”。
- 尽量避免纯数值但无感知的成长。
- 武器升级要有方向差异，不只是伤害更高。
- 被动升级要支持 build 构筑，而不是平均摊平。

## 敌人与节奏设计原则
- 前期给玩家建立掌控感。
- 中期引入压力与空间压缩。
- 后期制造 build 检验与生存挑战。
- 敌人差异至少体现在速度、血量、行为、威胁方式之一。

## 示例内容框架
### 敌人原型
1. 近战追击怪：移动快，血低，压迫走位
2. 肉盾怪：移动慢，血高，制造墙体感
3. 远程怪：周期发射弹幕，逼迫位移

### 升级项方向
- 攻击力提升
- 攻击范围扩大
- 攻击频率提升
- 投射物数量增加
- 击退增强
- 移动速度提升
- 最大生命提升
- 吸血或击杀回复
- 暴击率或暴击伤害
- 特殊效果：燃烧、连锁、穿透、分裂

## 流派分支与定向成长设计

### 目标
- 为玩家提供多个可识别、可持续成长的玩法流派
- 让玩家在开局就能建立本局成长方向
- 提升 build 构筑感，减少中期升级选择过于发散的问题
- 在定向构筑的同时保留一定随机性和变数

### 流派方向
- 肉盾流：高生命、高减伤、贴脸生存、反击类收益
- 负面流：围绕中毒、灼烧、诅咒、易伤、减速等负面状态叠加收益
- 地图建筑流：围绕炮台、陷阱、召唤物、地形生成物进行战斗
- 后续允许扩展更多流派，如暴击流、召唤流、位移流、爆发流等

### 开局分支选择
- 玩家在开局阶段可从多个预设流派中选择一个作为本局主分支
- 主分支决定本局升级收益卡的主要刷新倾向
- 分支选择应提供简短说明，明确该流派的核心战斗风格与成长方向

### 升级收益卡刷新规则
- 选择某一流派后，后续刷新的升级收益卡应优先出现与该流派相关的内容
- 每次刷新允许大部分卡来自所选分支，同时保留少量非该分支内容，避免构筑完全锁死
- 非本分支卡应优先为中性通用收益，或可与当前分支形成副构筑联动的内容
- 避免频繁刷出与当前分支完全无协同的卡牌

### 推荐刷新倾向
- 可采用 3 选 1 或 4 选 1 的升级卡方案
- 其中大部分选项应偏向当前主分支
- 允许固定保留 1 个非本分支选项，用于转型、混搭或通用补强

### 设计原则
- 分支要有明显风格差异，不只是数值换皮
- 每个分支都需要有核心收益、成长节点、成型标志
- 分支定向不能过强到让每局完全相同
- 随机性要服务于构筑，而不是破坏构筑
- 允许玩家在局中逐步强化主分支，也允许有限度跨分支构筑

## 地图事件：特殊技能卡系统

### 目标
- 提升局内随机性与探索收益
- 让玩家在路线选择中考虑风险与收益
- 为 build 形成增加临时变数和爆点

### 基础规则
- 地图房间中有概率刷新“特殊技能卡”
- 特殊技能卡分为：
  - 增益技能卡：提供随机 buff
  - 风险技能卡：高收益，但可能附带 debuff
  - 未知技能卡：效果完全随机，可能为 buff / debuff / 混合效果

### 刷新规则
- 每层地图按一定概率生成 1~3 张特殊技能卡
- 精英房、隐藏房、事件房可提高特殊技能卡出现概率
- 同一小局内，特殊技能卡总刷新数量应有上限，避免随机性过载

### Buff 类型池
- 攻击提升
- 攻速提升
- 暴击提升
- 移速提升
- 生命恢复
- 击杀回复
- 技能冷却缩短
- 投射物数量增加
- 元素伤害附加

### Debuff 类型池
- 最大生命降低
- 移速降低
- 攻击间隔变长
- 受击伤害提高
- 技能冷却变长
- 回血效率降低
- 视野/拾取范围降低

### 风险收益原则
- 纯增益卡：收益中等，稳定
- 风险卡：收益更高，但附带明确代价
- 未知卡：波动最大，适合赌运气流派

### 稀有度规则
- 普通：单一 buff / debuff
- 稀有：两个效果组合
- 传奇：强力 buff，但附带明确副作用或构筑限制

### 玩家信息展示
- 已知卡：展示明确效果
- 未知卡：只展示倾向，如“更可能是增益”或“高风险”
- 需要有清晰的拾取反馈、图标、颜色和音效区分

### 与 Build 的关系
- 特殊技能卡的效果应尽量可与现有武器、被动、元素系统联动
- 避免出现完全无用的随机效果
- 随机结果应优先从“当前 build 可用效果池”中抽取一部分内容wa


## 武器定义：烧伤法球

### 类型定位
- 武器类型：法球类攻击武器
- 攻击形式：投掷型
- 伤害类型：火焰 / 持续灼烧
- 定位：范围消耗、区域压制、持续伤害

### 核心表现
- 角色释放一个火焰法球并向目标方向投掷
- 法球飞行后落地
- 落地点生成一个范围灼烧区域
- 灼烧区域持续一段时间，对范围内敌人造成持续伤害

### 攻击规则
- 法球命中地面后不立即消失伤害，而是生成地面火焰区域
- 地面火焰区域在持续时间内周期性对敌人附加灼烧效果
- 灼烧效果可造成持续伤害
- 是否允许叠层需要单独定义，默认不无限叠加

### 数值参数
- 投掷距离：
- 飞行速度：
- 爆发半径：
- 灼烧区域半径：
- 灼烧持续时间：
- 灼烧触发间隔：
- 单次灼烧伤害：
- 是否可叠加：

### 联动方向
- 可归类为：法球流 / 火焰流 / 负面状态流 / 范围控制流
- 可与以下效果联动：
  - 增加投掷数量
  - 增加范围
  - 延长地面区域持续时间
  - 强化灼烧伤害
  - 对灼烧目标附加额外效果

### 设计限制
- 灼烧区域不能过大到覆盖全部战场
- 持续伤害频率不能高到造成性能和数值失控
- 需要保证玩家能清楚识别落点与灼烧范围

### 表现要求
- 法球飞行时有明显火焰弹道表现
- 落地时有爆裂或点燃反馈
- 地面灼烧区域需要有持续特效和清晰边界
- 敌人进入区域后要有被灼烧反馈

## UI规范：升级弹窗统一表现

### 目标
- 所有升级弹窗保持统一的视觉风格和信息结构
- 提升升级选择界面的可读性、识别度和整体美术一致性
- 让玩家在短时间内看清“这是什么、有什么效果、值不值得选”

### 统一要求
- 所有升级弹窗使用统一的版式结构
- 所有升级弹窗使用统一的字体、字号层级、边距、圆角、描边和按钮风格
- 标题、说明、图标、稀有度、效果描述的位置保持一致
- 同类信息使用一致的颜色和视觉规则，不允许同一类信息在不同弹窗里表现不一致

### 信息结构
- 顶部：升级名称
- 次级信息：类型 / 稀有度 / 流派标签
- 中间：核心效果描述
- 底部：选择按钮或确认按钮
- 可选内容：图标、关键词高亮、简短提示语

### 视觉要求
- 风格统一、简洁、清晰
- 优先保证可读性，其次再追求装饰性
- 升级卡之间要有明确层级差异，但不能过度花哨
- 稀有度、正面效果、负面效果要有清晰区分
- 弹窗整体需要比当前版本更精致、更稳定，避免廉价感和临时拼接感

### 交互要求
- 每个升级选项默认都要易读、易点、易比较
- hover、选中、确认状态需要有统一反馈
- 不允许不同升级弹窗使用完全不同的对齐方式和按钮逻辑

### 验收标准
- 任意升级弹窗放在一起时，玩家能明显感受到是同一套UI系统
- 玩家能在短时间内看懂升级内容
- 新增升级弹窗时可以直接复用现有模板，不需要重新设计布局


## 需求输出模板
当你给代码 Agent 提需求时，采用下面结构：

### 功能名称
例如：经验升级三选一系统

### 目标
玩家在升级时从 3 个随机项中选 1 个，立即获得成长反馈。

### 规则
- 升级时暂停战斗
- 从升级池随机抽 3 个不重复选项
- 已满级项不再出现
- 选择后立即生效

### 需要的数据
- 升级项 ID
- 名称
- 描述
- 稀有度
- 最大等级
- 效果参数

### 验收标准
- 玩家每次升级都能正常弹出选项
- 选择后属性变化立即生效
- 不出现空选项或重复异常

## 数值调优原则
- 优先保证“每分钟都在变化”。
- 升级收益应让玩家能感知到 build 成型。
- 若局内过于平缓，就增强风险或强化奖励峰值。
- 若局内过于随机，就增加保底机制或 build 导向机制。

## 与试玩 Agent 协作
重点接收以下反馈：
- 哪个阶段无聊
- 哪个升级项没人会选
- 哪种敌人只烦不有趣
- 哪个 build 太弱或太超模

## 与代码 Agent 协作
- 把抽象玩法拆成规则、数据、边界条件
- 避免只给概念，不给执行标准
- 每次新增内容时说明优先级与版本目标

## 版本路线建议
### v0.1
打通单局闭环

### v0.2
补足 build 差异与敌人组合

### v0.3
加入特殊事件、精英怪、局外成长或角色差异

## 成功标准
- 每一波次原型具备明确成长感
- 玩家每 30~60 秒都有一次新的决策或强度变化
- 不同升级组合能产生可辨认的 build 倾向


## 分支丰富度与武器辨识度设计规范

### 目标
- 每个玩法分支都需要有明确主题、独特战斗方式和稳定成长路径
- 不允许不同分支只是在同一套玩法上更换数值或伤害颜色
- 每个分支都需要让玩家在短时间内看出“这是另一种玩法”

### 分支设计要求
每个分支在设计时必须同时定义以下内容：
- 核心主题
- 核心战斗方式
- 核心资源或机制
- 主要成长方向
- 专属收益类型
- 专属弱点
- 推荐武器类型
- 推荐升级词条
- 推荐联动系统

### 武器差异化要求
每个分支的代表武器必须至少在以下 4 个维度中明显区别于其他分支：
- 攻击形式
- 命中后的效果
- 范围形态
- 输出节奏
- 风险收益关系
- 与敌人距离的关系
- 与地形或地图物件的关系

### 禁止事项
- 不允许多个分支只是在同一种武器上替换元素属性
- 不允许多个分支共用完全一致的攻击逻辑，只改名称或图标
- 不允许所有分支都依赖同一种成长思路
- 不允许分支之间只有数值差异，没有机制差异

### 分支最低配置
每个分支至少需要包含：
- 1 个核心机制
- 3 个代表性武器或技能方向
- 3 个专属升级收益
- 1 个明显短板
- 1 个与其他分支不同的成型体验

## 武器攻击范式与动作表现规范

### 目标
- 不同流派不能全部复用“持枪发射子弹”的同一攻击模式
- 武器类型需要形成明显差异，包括攻击距离、攻击方式、动作表现和命中反馈
- 近战武器必须具备独立的挥砍或斩击体验

### 武器分类
所有武器设计必须明确归类，不允许默认都按远程枪械处理。
至少支持以下类型：
- 近战武器：刀、剑、斧、锤、长枪等
- 远程武器：枪械、弓、法杖射弹等
- 投掷武器：飞刀、燃烧法球、炸弹等
- 区域武器：地面火焰、毒池、雷区等
- 建筑武器：炮台、图腾、陷阱等

### 近战武器要求
- 近战武器必须通过挥砍、突刺、横扫、重击等动作进行攻击
- 近战武器应具备清晰的攻击范围形状，例如扇形、弧线、直线突刺
- 近战武器需要有前摇、出手点和收招感
- 近战武器应有明确的攻击动作表现，不能仅用子弹替代
- 刀、剑等武器应优先使用挥砍动作，并有与动作一致的命中判定

### 分支设计限制
- 不同流派不能只更换武器名字和伤害属性
- 若某流派使用近战主题，则其代表武器必须以近战攻击范式实现
- 若某流派强调贴身战斗，则不能继续使用默认枪弹逻辑伪装成近战

### 表现要求
- 近战武器至少需要待机、攻击动作和命中反馈
- 挥砍类武器需要有明显的挥动轨迹或斩击表现
- 攻击动作与伤害判定时机需要基本一致

## 角色动画与武器表现规范

### 目标
- 角色战斗表现不再以程序生成的小图帧动画为主
- 武器特效攻击动画帧必须以 Spine 骨骼动画或 Spine 导出帧为正式表现标准
- 优先使用可复用的角色动作、武器模型和特效分层方案
- 不同武器需要通过独立动作和挂点表现形成明显差异
- 近战、远程、投掷、施法都应有不同的动作语言

### 设计原则
- 角色动作、武器模型、命中特效应分层设计
- 动画表现应优先支持挥砍、突刺、投掷、施法、开火等动作类型
- 武器不应再统一表现为“拿枪发子弹”
- 不同流派武器要在动作、轨迹、命中表现上有明显区别
- 攻击动作应表现出类似示例图那种连续中间帧、姿态变化和挥砍弧光，而不是静态贴图硬切

### 表现结构
- 角色主体动作
- 武器独立模型或部件
- 武器挂点
- 轨迹特效
- 命中特效
- 地面区域特效

### 动作要求
- 近战武器需要有挥砍、连斩、重击等动作
- 投掷类武器需要有抛出和离手动作
- 法球/施法类武器需要有施法前摇和释放动作
- 动画时机要与攻击判定基本一致
- 一套正式攻击动画至少应包含起手、出手、命中峰值、收招四段
- 武器挥动轨迹或施法轨迹需要和角色身体动作同步，不允许各自独立漂浮

### Spine表现要求
- 武器特效攻击动画帧必须由 Spine 源资产生成，或由 Spine 导出后再接入项目
- 角色、武器、斩击弧光、命中特效应保持分层，便于替换和复用
- 视觉参考应接近连续挥砍帧或连续施法帧的表达，而不是只做平移、缩放、换色
- 美术输出时需要保证玩家能直接看出攻击的起手方向、命中瞬间和收招过程

### 禁止事项
- 不再优先使用程序生成的静态像素图案充当正式攻击动画
- 不允许继续使用脚本直接生成正式攻击帧资源替代 Spine 动画
- 不允许所有武器共用同一套开火动作
- 不允许只换颜色或贴图来伪装不同武器表现

## Player角色结构与近战演出规范

### 场景结构要求
- 玩家角色标准节点树必须使用：
  - `AnimatedSprite2D`
  - `CollisionShape2D`
  - `Hurtbox`
  - `AttackPoint`
  - `WeaponPivot`
  - `SlashHitbox`
  - `AnimationPlayer`
- 武器本体、轨迹特效、命中特效都必须挂在 `WeaponPivot` 下
- `AttackPoint` 和 `SlashHitbox` 必须明确存在，不允许继续只靠代码里临时算点位

### 表现原则
- 角色主体动画与武器动画要分层
- 角色姿态变化由 `AnimatedSprite2D` 承担
- 武器挥动、轨迹和命中特效由 `WeaponPivot` 及其子节点承担
- 近战攻击判定区域应和角色挥砍方向一致，不能只有特效没有对应判定挂点

### 剑攻击顺序要求
- 剑系攻击动画顺序固定为：
  - `idle`
  - `ready`
  - `slash`
  - `followthrough`
  - `recover`
  - `idle_end`
- 这一顺序对应你提供的剑攻击顺序图，后续迭代同类武器时应保持一致的动作语义
- `slash` 是主要命中帧，`followthrough` 和 `recover` 负责收势，不能把命中表现挤到最后

### 后续约束
- 后续角色动画改动默认以 `AnimatedSprite2D + WeaponPivot + SlashHitbox` 这套结构继续扩展
- 若引入更复杂时序，可以把控制迁到 `AnimationPlayer`，但节点结构本身不能丢

## 剑客专属技能：瞬影剑阵

### 技能定位
- 爆发输出技能
- 多段范围斩击
- 短时间强化剑客清场能力
- 用于处理精英、小 Boss 和密集敌群

### 设计说明
该技能参考“高速残影、多段斩击、短暂无敌感、范围内连续斩杀”的大招体验，但必须做成原创表现，不直接照搬任何现成角色技能。

### 核心效果
剑客进入短暂的高速剑舞状态，在目标区域或自身周围释放多段残影斩击，对范围内敌人造成连续伤害。

### 基础规则
- 释放技能后，剑客短时间进入剑阵状态。
- 技能期间生成多个残影斩击轨迹。
- 每段斩击对范围内敌人造成伤害。
- 对同一敌人可多次命中，但必须有单体命中上限，避免 Boss 秒杀失控。
- 技能期间可以提供短暂无敌、减伤或不可被选中效果，但持续时间必须很短。
- 技能结束后进入短暂收招时间。

### 第一版推荐参数
- 技能冷却：18 秒
- 持续时间：1.2 秒
- 斩击次数：5 次
- 单段伤害：攻击力的 70%
- 同一目标最大命中：4 次
- 范围半径：160
- 释放期间减伤：50%
- 收招时间：0.25 秒

### 技能表现
- 剑客瞬间进入高速状态。
- 身边出现多个残影。
- 敌人周围出现斩击线。
- 每次斩击有清晰刀光。
- 最后一击可以有更大的十字斩或圆形斩击。
- 技能结束后残影消散。

### 技能动画需求
- 起手：收剑、蓄势、身体压低。
- 释放：高速残影、多段刀光。
- 终结：大范围斩击或回到原位。
- 收招：短暂硬直。

### 命中反馈
- 每段斩击需要有轻微停顿感或闪光。
- 命中敌人时触发刀痕、火花或冲击。
- Boss 被多段命中时不能过度遮挡画面。
- 普通敌人可被轻微击退。

## 剑客专属升级方向

### 方向 A：多段斩击强化
强化斩击数量和伤害频率。

升级示例：
- 斩击次数 +1
- 技能持续时间 +0.2 秒
- 每次斩击伤害提高
- 最后一击伤害提高
- 对生命低于一定比例的敌人造成额外伤害

适合流派：
- 攻击流
- 暴击流
- 近战流

### 方向 B：残影分身强化
让技能产生残影或额外攻击源。

升级示例：
- 释放技能时生成 1 个残影协同斩击
- 残影继承部分攻击力
- 残影优先攻击最近敌人
- 技能结束后残影保留短暂时间
- 残影攻击可触发部分近战效果

适合流派：
- 召唤流
- 攻击流
- 异常流

### 方向 C：生存闪避强化
提升剑客释放技能时的安全性。

升级示例：
- 释放期间短暂无敌
- 释放期间减伤提高
- 技能结束后获得护盾
- 技能命中敌人时回复少量生命
- 技能击杀敌人后减少冷却

适合流派：
- 肉盾流
- 近战流
- 高风险爆发流

### 方向 D：异常斩击强化
让剑阵附带异常状态。

升级示例：
- 斩击附加流血
- 斩击附加灼烧
- 斩击使敌人易伤
- 对异常状态敌人造成额外伤害
- 技能最后一击扩散目标身上的异常状态

适合流派：
- 异常流
- 负面状态流
- 火焰 / 毒 / 诅咒构筑

- **元素扩散**：被轰炸命中的异常敌人会将异常状态扩散给附近敌人。

### 传奇级
- **天穹坠落**：环域轰炸结束时落下一次巨型终结轰炸。
- **永续法阵**：轰炸命中敌人可略微延长法阵持续时间，有上限。
- **灾星领域**：轰炸圈内持续降低敌人移速与抗性。
- **双环术式**：生成内外两层轰炸圈，内圈高伤，外圈控制。
- **奥术风暴**：技能持续期间轰炸频率随时间逐渐提高。
